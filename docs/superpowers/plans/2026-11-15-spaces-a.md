# Spaces sidebar, Go to, and Send back implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Each assigned track works inline in its own worktree, without nested subagents. Review the integrated change once, not after each task.

**Goal:** Ship the local Spaces list, machine grouping in Agents, named Go to targets, Cmd-Shift-E parking, default-folded consoles, and intentional-only notifications with configurable sound.

**Architecture:** Keep the existing sidebar Views and picker overlay, with pure projections and exact release-specific patches. Delegate child opens to existing authenticated IPC and placement. Keep production version selection out of A and deliver A's live files through maintainer sync. Store explicit notification events independently of Herdr and project them into the existing panel feed.

**Tech stack:** JavaScript mod assets with TypeScript declarations, Herdr GPUI mods, TypeScript host and setup code, Vitest, fake hc, and the existing isolated-app acceptance framework.

**Spec:** [Spaces sidebar, Go to, and Send back](../specs/2026-11-15-spaces-a-sidebar-design.md).

## Global constraints

- Herdr app 0.1.13 and 0.1.16 are the required targets. Other releases are not certified by A.
- Spaces and tabs remain defined on this computer. Background jobs continue without panes.
- A does not widen the patch engine's supported-version gate. A separate final compatibility task owns that change.
- Selecting a native remote agent still focuses its box-owned pane until B supplies a local proxy. Do not show Unavailable here.
- Never launch, quit, restart, focus, or send input to the live app or its terminals. Never stop the default core.
- A's live rollout is a maintainer sync of checked mods and key fields, with backups and compare-writes.
- Use neutral `#161618` glass at 94 percent opacity, a 12-pixel panel radius, seven-percent white hover, and eight-percent white selection.
- Use JetBrains Mono for paths, agent names, and machine names. Use Google Sans Flex for labels and medium-weight headings.
- No coloured letter badges, new border, outline, or shadow. Red and amber mark state. The moved six-pixel green connection dot is the explicit exception.
- Keep `global["cmd-shift-w"] = "pane.close"` and the five existing terminal key sequences, including Ctrl-V image paste.
- Console groups start folded, with a caret and live consoles pill. Subagent rows stay visible, and Go to ignores sidebar folds.
- Only `spider notify` creates panel notifications. `sounds.enabled` is false on both releases. Only 0.1.16 suppresses native automatic agent toasts, through its layout-selected `spider-toast`. Leave stock toast untouched on 0.1.13.
- `herdr.notifications.sound` defaults to true. New intentional attention or urgent notices use `playSound("blocked")`; low urgency uses `playSound("done")`. No app means storage only, never an app launch.
- Intentional sound defaults on as a recorded design choice, with an explicit off setting. On 0.1.16, `setBadge` shows the undismissed attention and urgent count even while the panel is hidden. Native park-and-reopen on both releases is a blocking acceptance gate; keep the guide warning until it passes.
- Public fixtures contain synthetic sessions and machines `box-1.invalid` and `box-2.invalid`, never installed private props or session data.

## Focus areas

1. A qualified native remote agent with no local tab still focuses its real pane. Task 2.1 pins this exception.
2. A local roaming proxy names its remote machine but is focused through its local pane, with no duplicate session row. Tasks 1.2 and 2.1 pin this.
3. A feed generation changes while Enter or click is pending. Task 2.2 rejects the old capability without a duplicate launch.
4. A pre-existing global shortcut or malformed journal must not be overwritten as an owned default. Task 3.1 pins refusal and field-scoped rollback.
5. A notification arrives while the app is absent, its owner changes generation, a second panel reads it, or sound is disabled. Tasks 2.4, 2.5, and 2.6 pin durable storage, fresh-target activation, badge counts, and intentional-only sound. Task 3.3 pins combined settings ownership and 0.1.13 stock-toast immutability. The Task 4.1 and 4.2 splits pin composed anchors and native results.

## Shared interfaces

Add the declarations beside JavaScript assets, following `assets/agents/children.d.ts`. Import `SessionFeed`, `HerdrLabelContract`, `IpcDescriptor`, and `SessionIpcRequest` from `src/contracts.ts`. Reuse `AgentTerminal` and `ChildRow` from the existing children declaration. Define only the Herdr snapshot fields these projections read.

```ts
type NativeAgent = {
	address: string; pane: string; space: string; space_name: string;
	tab: string; title: string; program: { name: string; key?: string };
	status: string; pinned: boolean; focused: boolean;
};
type SpaceSnapshot = {
	id: string; index: number; name: string; machine: string | null; active: boolean;
	tabs: { id: string; name: string; active: boolean; status: string | null }[];
};
type PaneSnapshot = { pane: string; terminal: string | null; tab: string; cwd: string | null };
type NavigationSnapshot = {
	coreId: string; destination: Destination; agents: readonly NativeAgent[]; terminals: readonly AgentTerminal[];
	panes: readonly PaneSnapshot[]; spaces: readonly SpaceSnapshot[];
	feeds: readonly SessionFeed[]; contract: HerdrLabelContract;
	machines: readonly { name: string | null; layout: string }[];
	now: number; completedHours: number; completedRows: number;
};
type NavigationAction =
	| { kind: 'focus'; pane: string }
	| { kind: 'ipc'; descriptor: IpcDescriptor; request: SessionIpcRequest }
	| { kind: 'keep'; terminal: string };
type NavigationTarget = {
	id: string; kind: 'agent' | 'subagent' | 'console'; ownerId: string | null;
	sessionId: string | null; terminal: string | null; pane: string | null;
	space: string | null; tab: string | null; name: string; path: string | null;
	status: string; machine: string | null; retained: boolean;
	action: NavigationAction | null;
};
type Destination = { space: SpaceId; tab: TabId } | null;
```

Stable IDs are `session:<sessionId>`, `agent:<qualified-address>` for native agents without a matching feed, `run:<sessionId>:<runId>`, and `console:<sessionId>:<runId-or-empty>:<qualified-address>`. Machine identity is null for This computer. Selection and folds use IDs, not labels or array indices.

Track 2 adds these authoritative contract types in `packages/herdr/src/contracts.ts`:

```ts
type NotificationUrgency = 'low' | 'attention' | 'urgent';
type IntentionalNotification = {
	id: string; createdAt: number; title: string; body: string;
	kind: 'intentional'; scope: 'session'; sessionId: SessionId;
	ownerAddress: TerminalAddress; urgency: NotificationUrgency;
} & (
	| { runId: null; action: { kind: 'focus-owner'; sessionId: SessionId; address: TerminalAddress } }
	| { runId: RunId; action: { kind: 'open-run'; sessionId: SessionId; runId: RunId } }
);
```

Add that variant to `PanelNotification`. The shared feed parser verifies the action matches `runId` and the containing session identity. `HerdrConfig.notifications` and `InstalledModProps.notifications` are `{ sound: boolean }`, with a true default and backward-compatible absent props. Track 3 implements parsing and copying. Track 3 extends the existing `InstalledModProps` declaration in `packages/herdr/src/setup/installer.ts`; it does not create a second Herdr config schema.
